# 🩺 OralAI — AI-Powered Oral Cancer Screening Platform

OralAI is a modern AI-assisted web platform designed for **early oral cancer screening** using deep learning concepts and medical image analysis workflows.

The platform provides an interactive and futuristic UI where users can:

- Learn about oral cancer
- Understand symptoms & risk factors
- Upload oral cavity images
- Simulate AI-based screening results
- Experience a healthcare-focused AI workflow

---
